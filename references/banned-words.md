# 禁用词与替换建议

这份表列的是黑话、圈内行话与自造复合简称。判断标准比词表要紧，先读标准，再查表。

## 判断标准

换成一个准确朴素的书面词，句意无损的，就换。词表会过期，标准不会。

换词时按两步走：先问这句话要给谁看，再问这个词换成普通话会损失什么信息。答不上来、只能答「大家都这么说」的，就换。

词表是候选名单，不是许可证。表里没有的词，用标准照样判；表里有但换了会走意的，按上面第 1 节优先级处置，不必硬换。

**例外**：风险提示、安全警告、合规声明里的提示语（「需要注意的是」这类）不受本表约束，照写。见主规程第 1 节与第 4 节。

## 一、黑话

| 禁用 | 替换建议 |
|---|---|
| 讲透 | 讲清楚、说清 |
| 硬核 | 严格、扎实、要求高（按语境选） |
| 更硬 | 更严格、更强、更不留余地 |
| 打法 | 做法、办法、策略 |
| 赋能 | 支持、提供能力、让……能用 |
| 底层逻辑 | 原理、根本原因；多半直接写是什么，不必说这个词 |
| 说白了 | 直接说；多数可删，删掉后句子自己会说话 |
| 值得一提的是 | 删，直接写那件事 |
| 需要注意的是 | 正文里删，直接写要注意什么；风险与安全提示里保留 |
| 干货 | 具体做法、可用的内容；多半可删 |
| 拉满 | 做到头、开到最大、用足 |
| 抓手 | 可以着手的地方、切入点、办法 |
| 闭环 | 首尾接上、把流程走完整；最好写明从哪一步到哪一步 |
| 颗粒度 | 精细程度、详细程度 |
| 一键搞定 | 一步做完、自动完成 |
| 收着（如「这个选项收着生活职业，也收着收集、养成」） | 涵盖、包含（「这个选项涵盖生活职业，也包含收集、养成」）。把动词当容器用，读者要在脑子里还原一遍才知道是「包含」 |

变体一并算在内。「打通闭环」「拉满细节」「讲透逻辑」这类组合词，按上面的替换逐字换掉，不要整体保留。

## 二、圈内行话

对内人顺口，对读者是障碍，说明文里一律换掉。

| 禁用 | 替换建议 |
|---|---|
| 收口 | 收尾、汇总、定稿（按语境选） |
| 合手 | 顺手、合用 |
| 落地 | 实施、做到、实行（按语境选） |
| 齐的 | 都准备好了、齐全 |
| 过目 | 看一下、审一遍 |
| 出面 | 由……去说、由……来协调；写明是谁去做什么 |

## 三、自造复合简称

把动词挤进名词造出来的简称，读的人要在脑子里还原一遍才读得下去。

| 禁用 | 还原成 |
|---|---|
| 主玩款 | 主玩的游戏、最常玩的那一个 |
| 自报款 | 自己报告的那一个、受访者自报的那一个 |
| 抽样款 | 抽样得到的那一个 |
| 款号 | 代数 |

判断办法是把那个词拆开，看能不能还原成一句自然的话。还原不了的就写完整短语，宁可多三个字。

**量词与名词规范**：不要用「款」作量词或名词，一律换成「个」与「游戏」——「十七个游戏」「每个游戏」「逐个游戏」「一部新作」。这条覆盖全表，不是只针对上面三个例子。
