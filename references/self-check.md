# 交付前自检

逐条过，看事实不看感觉。前十五条在交付前全部走一遍；发现禁用词、结构提示语或主语缺失，必须在输出前改掉，不得带病交付。

## 清单

1. 禁用词、行话、翻译腔直译有没有？有就换（风险与安全提示除外）。
2. 结构提示语有没有？全删。
3. 指代：每个代词是否只指一个对象？同一个对象是否固定一个称呼？不同概念是否用了不同的词？新概念是否在首次出现时定义过？
4. 段落：有没有超过五句或缩成一句？分号、破折号是否各超过一处？有没有超过四十五字的整句、超过二十四字的分句？
5. 把各段第一句连着读，句式是否同模子？把各段最后一句连着读，是否每句都在盖章？
6. 形态：参考性内容做成表格了吗？操作步骤分条了吗？有没有把清单伪装成句子的段落？
7. 每个判断后面跟了具体到能看得见的东西吗？
8. 结尾：一般文章是否没有空泛总结、没有突然换口吻？文档、报告、邮件是否写出了结论或下一步？
9. 有没有自造的复合简称（「主玩款」这类）？拆开读一遍，还原不成自然短语的就写全。
10. 每个数字能不能就地读出它的分母与出处？「累计口径」「当期」这类词有没有指明是谁的、指的是什么？
11. 主语是否每一句都清楚？有没有连续三句以上无主语？主语中途换了，有没有交代？
12. 有没有用「可以」「需要」「建议」直接开头而不写谁可以、谁需要、谁建议？
13. 有没有报告输出？如果有，数字的分母与出处是否就地可读？结论与建议是否区分关联与因果？
14. 有没有审校定稿的定量分析报告？如果有，按 `report-writing.md` 第七节过一遍：保留清单里的读数与结论方向有没有被改动？有没有新增原文没有的结论、把未校正显著写成显著、把「未观察到差异」写成「两组相同」？口语与模糊表述有没有换成规范写法？
15. 这是给用户看的汇报、回执还是备忘？如果是，逐个数字问一遍：它的基数、分母、比较对象在这一句里读得出来吗？动词的宾语写全了吗？把这一节交给一个没看过前文的读者，他能复述出每个数说的是什么吗？
16. 汇报与说明里有没有生造缩略词或省掉主谓宾的半截话？先看量词后面有没有带出中心名词（写「298 个单元格」，不写「298 格」）。再看问卷题干与指标有没有写全，或者按语义归类（不写「推荐今天这个游戏、推荐基准游戏」）。动作词也核一遍，有没有缩成单字或生僻简称（写「重新导出」，不写「重出」）。
17. 有没有为了躲避分条，在同一个句子里连用三个以上顿号「暗中报菜名」？如果有，先把四个以上的并列细项按语义归成上位类别再分句叙述，或者直接拆成 Markdown 表格。
18. 这是访谈提纲、观察表说明或操作手册吗？如果是，检查四件事：段首是否按「栏目名（几字原则）：」起头？是否去掉了光秃秃的祈使句、改用「仅用于……，请勿……（括号补原因）」？行为示例是否凝练成四字短词并与前面的量词一致？定性观察点是否写明了前置游戏节点、删掉了冒号后的诱导性枚举分支、并把不同玩法环节拆成了独立条目？
19. 句子是不是都切成十五到二十字的平头短断言了？相邻三句的长度与句式是不是雷同？后一句有没有接住前一句的落点，还是各自干垒？有因果或先后关系的两三句合成一句复句，目的与原因放到主谓核心后面。这一条相对的是第 3.6.1 与 3.6.2 节。

第 1 到 10 条是常设项。第 11 到 19 条针对主力模型的高发失败模式（见主规程第 0 节与第 3.6 节），也针对报告、汇报、执行材料三类场景。生成较长文本时尤其要过。

## 附录 A：常见问题与改法

自检发现问题之后，按这张表改。结构提示语、盖章、主语这类问题的判定标准在主规程第 0 节，这里给处置办法。

| 问题 | 改法 |
|---|---|
| 出现结构提示语 | 删掉，直接写内容 |
| 每段用一句斩钉截铁的短判断收尾 | 段落不盖章，判断可以有，不必每段都交 |
| 每段起句是同一个句式 | 把各段第一句拎出来连着读，同模子就换：有的从具体事例起，有的从条件或让步起，有的承接上一段的尾巴 |
| 分号串起四个以上并列项 | 这是清单穿了句子的衣服。改用编号列表，或沿一条推进线重排 |
| 全篇短句、主谓跳换 | 那不是口语，是电报，补出主语与连接 |
| 几块内容是并列的，却硬揉成一段 | 沿一条推进线重排：先讲条件再讲结果，不要罗列 |
| 一处判断下完，接着跳到规则、再跳到工具、再跳到清单 | 缺过渡，补一句说明这几步之间是什么关系 |
| 小标题是个要读者猜的抽象名词（「读法」「口径」） | 写成它要说的那件事（「这些数字怎么读」），别拿一个定义不明的名词当路标 |
| 一句话里的数字找不到分母或出处 | 在这句或紧前一句里写出分母与来源；「累计口径」要指明是谁的，「当期」要换成具体时点 |
| 数字带不出背景（「有效 N 大于门槛」「末档抬头」） | 基数、分母、比较对象写进同一句；一句塞不下就拆句或做表。判定与例见主规程 0.7 |
| 动词的宾语被省掉（「不按字面用」「先不这么读」） | 补出宾语：不按字面解读「哪一档的什么」，读者要能不翻前文就答出来 |
| 句子切得太碎，全篇是十五到二十字的平头短断言 | 把有因果、目的或顺承关系的两三句短断言合成一句复句；目的与原因放到主谓核心后面作后置说明或收进括号 |
| 为了不分条，在一段话里连用多个顿号罗列四五项模块名或六七道题名 | 先按语义归并成上位类别（如「两对平行指标与两项留存指标」）再入句；需要逐项对照的直接做表格 |
| 操作说明像监工训话（「不用于……」「用你自己的话，简洁易懂就行」） | 改成「栏目名（核心原则）：仅用于……，请勿……（括号补原因）」，用「请记录客观事实，避免主观定性」替代口语说教 |
| 出现「差 298 格」「重出」「推荐基准游戏」这类生硬缩写 | 补齐量词后的中心名词（「298 个单元格」）、还原双音节动词（「重新导出」）、补全名词短语里的介词与中心语（「对基准游戏的推荐意愿」） |
| 观察点写着「拿到宝箱后怎么处置：直接点了、愣着找去处，还是……」 | 动作前补齐触发节点，冒号后删掉带推测的预设分支，不同机制环节拆成独立条目 |

## 附录 B：发现后怎么改

改法分两层。局部问题（禁用词、结构提示语、名词化、代词歧义）就地换词换句；整段问题（无主语贯穿全段、段落盖章、清单伪装成段落，以及短断言连击）不要在病句上打补丁，整段重写，重写时按「谁做什么」重排主语。判断收进一处，并列项提出来分条或做成表格。
